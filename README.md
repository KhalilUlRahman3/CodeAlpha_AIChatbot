
# AI Student Helpdesk Chatbot

A Java-based rule-driven chatbot that answers
student questions about Java and programming.

## Features

- Answers predefined programming questions.
- Uses keyword matching and text normalization.
- Supports custom FAQ training.
- Saves custom FAQs using file handling.
- Maintains conversation history.
- Includes helpful chatbot commands.
- Provides fallback responses for unknown questions.

## Technologies Used

- Java
- Object-Oriented Programming
- HashMap and LinkedHashMap
- ArrayList and HashSet
- String Processing
- Java File Handling
- Properties API

## Commands

- /teach: Add a custom question and answer.
- /faqs: View available questions.
- /history: View conversation history.
- /clear: Clear conversation history.
- /help: Display commands.
- /exit: Exit the chatbot.

## How to Run

1. Open the project in IntelliJ IDEA.
2. Open AIChatbot.java.
3. Run the main() method.
4. Start asking programming questions.

## Data Storage

Custom FAQs are saved in
custom_faqs.properties.

Console-based rule-driven chatbot.
